# ALX Backend JavaScript

This repository contains JavaScript and TypeScript exercises for the ALX backend curriculum. Each project directory has its own README with task notes and project-specific setup information.

## Projects and tasks

### [0x00 - ES6 Basics](./0x00-ES6_basic/README.md)

ES6 syntax and features: constants and block scope, arrow functions, default and rest parameters, spread syntax, template strings, object properties, iteration, and report objects.

Tasks: [0](./0x00-ES6_basic/0-constants.js), [1](./0x00-ES6_basic/1-block-scoped.js), [2](./0x00-ES6_basic/2-arrow.js), [3](./0x00-ES6_basic/3-default-parameter.js), [4](./0x00-ES6_basic/4-rest-parameter.js), [5](./0x00-ES6_basic/5-spread-operator.js), [6](./0x00-ES6_basic/6-string-interpolation.js), [7](./0x00-ES6_basic/7-getBudgetObject.js), [8](./0x00-ES6_basic/8-getBudgetCurrentYear.js), [9](./0x00-ES6_basic/9-getFullBudget.js), [10](./0x00-ES6_basic/10-loops.js), [11](./0x00-ES6_basic/11-createEmployeesObject.js), [12](./0x00-ES6_basic/12-createReportObject.js). The `100-main.js` and `101-main.js` runners refer to task implementation files that are not present.

## Repository hygiene

Install dependencies from the `package.json` in the project you are working on. Dependency installations under `node_modules/` are intentionally ignored by Git.
